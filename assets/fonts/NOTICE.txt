Fonts used only to draw the Open Graph share cards (src/lib/seo/og-card.tsx).
next/og cannot read WOFF2 or variable fonts, so these are static, Latin-subset
TTF instances made with fontTools from the WOFF2 files next/font self-hosts.

BricolageGrotesque-Medium.ttf    Bricolage Grotesque, wght 500, opsz 36 (wordmark)
BricolageGrotesque-Bold.ttf      Bricolage Grotesque, wght 700, opsz 36 (wordmark)
BricolageGrotesque-SemiBold.ttf  Bricolage Grotesque, wght 600, opsz 72 (headline)
  Licence: OFL-BricolageGrotesque.txt (SIL Open Font License 1.1).
  Internal names state the instance, e.g. "Bricolage Grotesque 72pt SemiBold".

GBCCardSans-Medium.ttf           Modified from IBM Plex Sans (wght 500)
GBCCardMono-Medium.ttf           Modified from IBM Plex Mono Medium
  Licence: OFL-IBMPlex.txt (SIL Open Font License 1.1). IBM Plex declares the
  Reserved Font Name "Plex", so these modified (subset/instanced) versions are
  renamed "GBC Card Sans" and "GBC Card Mono" in their name tables. The original
  copyright notices are kept.
